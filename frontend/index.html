DIY Kronos Editor

Drag a .PCG file onto a pane to open it as a new dataset, or pick an already-open one from the selector above a pane -- both panes on the same dataset share edits. Each pane's Setlist/Programs/Combis/Duplicates tabs browse whichever dataset it's showing; drag a Setlist row within a pane to swap, drag across panes to copy (Programs/Combis rows aren't draggable yet).
